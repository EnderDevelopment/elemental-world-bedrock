# Minecraft Bedrock Texture UI Asset

Elemental World BE is a Minecraft Bedrock texture and user-interface artwork asset for a magical elemental-themed Bedrock Add-On. It provides a pixel-art-style elemental choice menu showing Fire, Water, Earth, Air, Lightning, Ice, Nature, Light, Shadow, and VOID, along with the awakening kit and rebirth potion visuals.

## Install

1. Download the project files from GitHub or the EnderDevelopment marketplace.
2. Locate `assets/gui/elemental_choice_menu.svg`.
3. Copy the SVG into the UI or resource asset workflow used by your Minecraft Bedrock project.
4. Convert or adapt the SVG if your Bedrock resource pack requires PNG or another supported texture format.
5. Reference the converted asset from your custom UI implementation.

This project contains the menu artwork only. It does not include a complete Bedrock behavior pack, functional element selection logic, custom items, entities, abilities, or bosses.

## Use

1. Add the menu asset to your Bedrock resource pack or custom interface project.
2. Display it as the visual background or layout reference for an element-selection screen.
3. Connect the visual choices to your own UI buttons and gameplay systems.
4. Use the included labels and artwork to represent the ten elements and the awakening kit.
5. Implement selection limits, rebirth behavior, items, powers, mobs, armor, and bosses separately in your add-on.
